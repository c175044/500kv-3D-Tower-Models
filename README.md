# 500kv-3D-Tower-Models
3D models of 500 kV transmission towers and conductors reconstructed solely from satellite imagery.
This repository contains the 3D tower and transmission line models generated in the paper "Satellite-Only 3D Digitization of Hundred-Kilometer-Scale High-Voltage Transmission Lines".
The model files  will be uploaded upon publication.
For any questions, please contact the corresponding author.
